## Mall Customer Analysis & Segmentation Dashboard

### Project Overview

This project presents an end-to-end Customer Analytics Solution designed to uncover insights from mall customer data. By combining Python (EDA), MySQL (data management), and Power BI (interactive dashboard), the project identifies key customer segments and spending behaviors to support data-driven business decisions.

The goal is to transform raw data into actionable insights that help businesses improve customer targeting, engagement, and revenue strategies.

### Objectives

Analyze customer demographics and spending behavior
Identify high-value and low-engagement customers
Perform customer segmentation using income and spending patterns
Build an interactive dashboard for business insights
Deliver data-driven recommendations

### Dataset Features

Customer ID
Gender
Age
Annual Income (k$)
Spending Score (1–100)
Age Group (Derived)
Spending Category (Derived)

### Tech Stack

Python (Google Colab) → Data Cleaning & EDA
MySQL → Data Storage & SQL Analysis
Power BI → Dashboard & Visualization
Excel (Optional) → Data Validation

### Workflow
Data Collection → Data Cleaning (Colab) → Feature Engineering → 
MySQL Database → SQL Analysis → Power BI Dashboard → Insights & Reporting

### Dashboard Highlights

KPI Cards (Total Customers, Avg Income, Avg Spending)
Customer Segmentation (Income vs Spending Scatter Plot)
Gender Distribution
Age Group Analysis
Spending Behavior Insights
Interactive Filters & Slicers

### Key Insights
High-income customers do not always have high spending behavior
A small segment of customers contributes significantly to revenue
Younger and middle-aged groups show higher spending patterns
Opportunity exists to convert high-income low-spenders into premium customers

### Business Recommendations

•	Focus marketing campaigns on high-income low-spending customers 
•	Introduce loyalty programs for high-value customers 
•	Create personalized offers based on age groups 
•	Use targeted ads for underperforming segments 
•	Enhance customer retention strategies for high-spending low-income groups
